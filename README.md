# TrustTunnel для OpenWrt

[English](README.en.md) · [Релизы](https://github.com/NooBiToo/TrustTunnelOpenWrt/releases) · [Подробное руководство](GUIDE.ru.md) · [Сообщить об ошибке](https://github.com/NooBiToo/TrustTunnelOpenWrt/issues)

**Выбранные сайты через VPN, остальной трафик напрямую. Настройка и диагностика в LuCI.**

`luci-app-trusttunnel` запускает клиент [TrustTunnel](https://github.com/TrustTunnel/TrustTunnel)
на роутере с **OpenWrt 25.12+**. Устройства домашней сети используют туннель через роутер:
устанавливать VPN-клиент на каждое из них не нужно.

- **Выборочная маршрутизация:** списки [itdoginfo/allow-domains](https://github.com/itdoginfo/allow-domains), свои домены и исключения.
- **Настройка в браузере:** импорт серверного конфига, выбор списков и управление службой в LuCI.
- **Понятная диагностика:** состояние туннеля, проверка домена, пинг сервера и сравнение внешних IP.
- **Два режима:** обход по списку или весь интернет-трафик LAN через VPN с учётом исключений; killswitch для выбранного трафика.

TrustTunnel — открытый VPN-протокол, изначально разработанный AdGuard VPN,
с транспортом на основе HTTPS и средствами противодействия DPI.

## Быстрый старт

### Что понадобится

- Роутер с **OpenWrt 25.12 или новее**, LuCI и пакетным менеджером `apk`.
- Доступ по SSH к роутеру и место для бинарника клиента и зависимостей.
- **Сервер TrustTunnel и конфиг подключения.** Пакет устанавливает клиент на роутер;
  сервер нужно настроить отдельно по [официальной инструкции](https://github.com/TrustTunnel/TrustTunnel#quick-start).
- Поддерживаемая архитектура клиента: `aarch64`, `armv7l`, `mips`, `mipsel` или `x86_64`.
  Проверить её можно командой `uname -m`.

OpenWrt 24.10 и более ранние версии с `opkg` не поддерживаются.
В режиме обхода по списку нужен `dnsmasq-full` с поддержкой `nftset` — установщик проверит это
и запросит подтверждение замены штатного `dnsmasq`.

### 1. Установите пакет

Выполните по SSH **на роутере**:

```sh
sh -c "$(wget -O - https://raw.githubusercontent.com/NooBiToo/TrustTunnelOpenWrt/main/install.sh)"
```

Установщик проверит совместимость, установит зависимости, пакет LuCI и бинарник клиента.
Замена `dnsmasq` на `dnsmasq-full` ненадолго перезапускает DNS.
После установки служба выключена: сначала настройте подключение.

### 2. Настройте подключение

1. Откройте **Службы → TrustTunnel → Настройки**.
2. На вкладке **Сервер** нажмите **Импорт…** и вставьте конфиг своего сервера
   либо заполните параметры вручную.
3. На вкладке **Списки** отметьте нужные сервисы или категории.
   При необходимости добавьте свои домены и исключения на вкладке **Свои домены**.
4. Включите запуск при загрузке, нажмите **Сохранить и применить**,
   затем **Запустить** на странице состояния.

### 3. Проверьте результат

На странице **Диагностика** проверьте конфигурацию и введите нужный домен,
например `youtube.com`: пакет покажет, попадает ли он в обход и почему.
Кнопка **Сравнить внешний адрес** позволяет проверить выход через туннель отдельно от прямого подключения.

## Два режима работы

| Режим | Что идёт через туннель | Когда использовать |
|---|---|---|
| **Обход по списку** — по умолчанию | Домены и подсети выбранных списков и свои домены | Нужен VPN для отдельных сервисов, остальной трафик идёт напрямую |
| **Всё через VPN** | Интернет-трафик LAN с учётом исключений | Нужен туннель для всей домашней сети |

Трафик самого роутера включается отдельной настройкой.
Демон Telegram из отдельного проекта [tgws-openwrt](https://github.com/NooBiToo/tgws-openwrt) ходит напрямую: его сокеты помечены `0x7467` и исключены из туннеля.
Подробнее: [режимы маршрутизации](GUIDE.ru.md#два-режима-работы) и [killswitch](GUIDE.ru.md#killswitch).

## Что важно знать

- В выборочном режиме домены сопоставляются через DNS роутера.
  Собственный DoH/DoT на устройстве может обходить это сопоставление.
- У сервиса может быть несколько доменов: используйте готовые списки и проверку домена.
- Общий IP у нескольких сайтов может привести к маршрутизации через туннель дополнительных доменов.
- Один сервер поддерживается; несколько профилей и автоматическое переключение между серверами пока не реализованы.
- Гостевые сети нужно добавить в настройки интерфейсов LAN отдельно.

Полный список особенностей и способов их учесть — в [ограничениях](GUIDE.ru.md#ограничения).
